15 NAT 与网络限制

本章要点：协议面向可信局域网， 不提供任何穿透能力；公网 NAT / 蜂窝网络不支持。 Client 必须能够主动向 Server 发起 TCP / UDP。

支持范围

网络形态支持
单一局域网支持
二级路由条件支持
跨公网 NAT / 蜂窝网络不支持

协议假设

假设说明
同一局域网双方在同一局域网内可达
Client 可主动向 Server 发起 TCP / UDP控制面由 Client 主动连接；数据面探测同样由 Client 发起
不提供穿透不做 NAT 打洞、端口预测或 relay
Client（同一局域网）
Server
TCP connect（控制面）
监听控制端口
UDP PROBE（数据面）
PROBE_ACK（从会话数据面端口发出）
Server 以 PROBE 报文的源地址:端口作为该会话的对端数据面地址（见 07 章）

实现建议

  • Client 先发 UDP 建 NAT 映射
  • mDNS 可能失效，需支持手动配置地址
与 04 章非目标一致：公网穿透与互联网规模传输不在本协议范围内； 跨公网场景需要由实现层（而非协议层）另行解决。
