05 协议栈（Protocol Stack）

本章要点：协议分为控制层（TCP）与数据层（UDP / TCP 兜底）两层， 两者相互独立：控制面拥有最终裁决权，数据面仅负责搬运与落盘。

分层结构

应用层 → 控制层 → 数据层 → 网络层
应用层 · 文件读写与业务语义
↓ 控制层（TCP：状态机 / 重传裁决 / 会话管理）
↓ 数据层（UDP / TCP：chunk 传输与兜底）
↓ 网络层（LAN）
数据层与控制层各自独立：一条控制连接承载 N 个会话时，数据面端口可以被多个会话共用 —— UDP 包头中的 session_id 足以区分（见 08 章）。

职责划分

职责归属
最终裁决权控制面拥有
搬运与落盘数据面仅负责
控制面与数据面相互独立数据面端口可以被多个会话共用（session_id 足以区分，见 08 章）
完成消息与缺失裁决完成消息由接收方发布；缺失裁决由接收方发起（见 10 章「视角定义」）

通道与成熟度

通道方向状态
TCP 控制面双向 v0.3.0 已定义（二进制定长帧格式、握手、权威快照、心跳）
UDP 数据面双向 v0.3.0 已定义（含 CRC32 变体与校验规则）
TCP 数据面兜底 v0.3.0 仅定义语义，未定义线路格式（见 07 章、26 章）
