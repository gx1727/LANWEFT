字段定义

字段 位宽 偏移
(BYTE)		 说明
session_id 32 0 会话唯一标识 (u32)，与 MQTT Session 一致
chunk_id 32 4 数据块索引，从 0 开始
payload_len 16 8 Payload 实际字节数
flags 16 10 控制位掩码 (见右侧)
payload N 12 原始文件数据
crc32 32 12+N 完整性校验 (Header + Payload)

Flags 定义 (16 bits)

Bit 0DATA普通数据包
Bit 1RESEND重传数据包
Bit 2LAST_CHUNK最后一个 Chunk
Bit 3PROBE探测 / 测试包
Bit 4-15RESERVED保留位 (Must be 0)

错误处理规范 (Error Handling)

  • 所有多字节字段必须使用 小端序 (Little-Endian)
  • CRC32 校验失败的包 必须丢弃 (MUST discard)
  • Session ID 不匹配的包 必须丢弃 (MUST discard)
  • Payload Length 非法的包 必须丢弃 (MUST discard)
  • chunk_id ≥ chunk_count 的包 必须丢弃 (MUST discard)

CRC32 变体 (CRC Variant)

  • 必须使用 CRC-32/ISO-HDLC (zlib crc32)
  • 多项式 0x04C11DB7 (反射 0xEDB88320)
  • 初值与末尾异或均为 0xFFFFFFFF，输入输出均反射
  • 校验值: "123456789" → 0xCBF43926
  • 覆盖区间: 12 字节头 + payload，不含尾部 CRC 字段本身
头部长度 HEADER_SIZE = 4 + 4 + 2 + 2 = 12 字节，CRC_SIZE = 4 字节； payload_len ≤ 1400 且 payload_len ≤ 协商 chunk_size，推荐 chunk_size = 1200 字节。
