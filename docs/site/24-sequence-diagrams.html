端到端时序图 (End-to-End Sequence)

实线 = 控制面 TCP 帧 · 虚线 = 数据面 UDP 包 · 灰框 = 说明 · 胶囊 = 状态转移

阶段与规范要点

阶段规范要点
① 控制连接建立login 必须是连接上的第一条消息；Server 之前的一切消息必须丢弃。login_ack.sessions 是权威快照。
② 会话建立Server 下发 session_id / chunk_count / window / chunk_size / udp_port / tcp_port；file_exists = 1 即走秒传路径。
③ UDP 探测PROBE 与 PROBE_ACK 共用 flags.bit3，以 payload_len 区分（4 / 5）；Server 必须以 PROBE 的源地址:端口作为对端数据面地址。
④ 数据传输无逐包 ACK；批量发送（burst_size，间隔 batch_gap_us 初值 2000 µs）；数据面不得改变状态机。
⑤ 缺失裁决接收方至少每 50 ms 下发 missing_chunks(report)，空列表也必须下发；发送方 1000 ms 未收到裁决须发 mode=request 索要。
⑥ 校验与提交位图全真 → VERIFY（Blake3）→ COMMIT（原子重命名）→ 发布完成消息；完成消息一律由接收方发布。
⑦ 中断与恢复断线重连走 login 恢复列表 + login_ack 权威快照；暂停后恢复走 resume_session / resume_ack；两者都使双方回到 TRANSFERRING。

状态机（10 章）

INIT → NEGOTIATINGupload_start / download_start
NEGOTIATING → TRANSFERRINGupload_accept / download_accept
NEGOTIATING → COMPLETED秒传（file_exists = 1）
TRANSFERRING → VERIFY位图全真（仅接收侧）
TRANSFERRING ⇄ PAUSEDsession_pause / resume_session
VERIFY → COMMIT → COMPLETEDBlake3 通过 → 原子重命名（仅接收侧）
任意 → ABORTEDsession_abort（终态，无出边）
两个视角的状态序列不同：接收侧经过 VERIFY / COMMIT，发送侧不经过； 发送侧的 TRANSFERRING → COMPLETED 与接收侧的 TRANSFERRING → VERIFY → COMMIT → COMPLETED 对应同一次完成。
