帧头字段定义

字段偏移大小类型说明
frame_len0-34u32本帧总字节数（含帧头）
msg_type41u8消息类型编号
flags51u8帧级标志位；bit0-7 全部保留
body_version61u8消息体布局版本号；初值 0
reserved71u8保留字节
body8..Nbytes消息体，长度 = frame_len − 8

帧级错误处理

情况处理
frame_len == 0丢弃并关闭连接（帧边界不可信）
frame_len > max_frame_len丢弃并关闭连接（帧边界不可信）
frame_len < 8按 SERIALIZATION_ERROR 丢弃该帧，连接保持
msg_type 未知按「未识别消息必须忽略」丢弃该帧，连接保持
定长区长度不足按 SERIALIZATION_ERROR 丢弃该帧，连接保持
变长区长度越界按 SERIALIZATION_ERROR 丢弃该帧，连接保持
reserved ≠ 0必须忽略，不得视为错误，连接保持
定长区数值违反取值约束按 SERIALIZATION_ERROR 丢弃该帧，连接保持

消息体编码约定

类型编码
u8 / u16 / u32 / u64小端序定长整数
boolu8，0 = 假，1 = 真；其他取值非法
enum8u8，取值见枚举表
stru16 长度 + UTF-8 字节（不含 NUL）；长度 0 表示无值

枚举

result0 = fail，1 = success
direction0 = upload，1 = download
state0 INIT · 1 NEGOTIATING · 2 TRANSFERRING · 3 PAUSED · 4 VERIFY · 5 COMMIT · 6 COMPLETED · 7 ABORTED
missing_chunks.mode0 = report，1 = request
proto_version三个 u8：major / minor / patch

TCP 特有约束

  • 控制连接必须启用 TCP_NODELAY（禁止 Nagle 合并）
  • 不得假设一帧一次 recv 到达 —— 必须按 frame_len 读满后再解析
  • 不得按换行或任何字节模式切分帧
  • 多帧可合并为一次 write，但不得延迟发送超过 50 ms
  • 无 CRC：TCP 自带字节流校验和与重传，控制帧不重复 CRC32
  • 心跳 ping 每 10 s；30 s 内无任何消息则关闭连接

帧长约束：frame_len ≥ 8（最小帧长即帧头长度）、frame_len ≤ 1 MiB（max_frame_len）。 body_version 与协议版本 proto_version 相互独立，当前所有消息的 body_version 必须为 0。
定长区一旦发布即冻结：新增字段只能追加在扩展区，既有字段的偏移与大小不得变更；接收方必须忽略扩展区的全部内容。
