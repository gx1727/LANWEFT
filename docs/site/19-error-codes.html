19 错误码（Error Codes）

本章要点：本章的错误码必须通过控制面消息上线路， 字段映射见下表；发送方与接收方必须按错误码做分支判断，不得解析 detail 自由文本。 result 字段只表达「成功 / 失败」，不承载错误码； 未列在本章的错误码一律视为 UNKNOWN_ERROR。

错误码上线路（规范性）

本章的错误码必须通过控制面消息上线路，字段映射如下：

消息 字段 语义
session_abort reason 终止原因，必填（str），取值来自本章
session_abort detail 可读补充说明（str），仅用于日志与 UI，不得用于逻辑判断
upload_complete code 失败时的错误码（符号名，str）；成功时为空串（长度 0）
download_complete code 失败时的错误码（符号名，str）；成功时为空串（长度 0）
asset_recall_complete code 未删除时的错误码（符号名，str）；成功删除时为空串（长度 0）
  • 发送方与接收方必须按错误码做分支判断，不得解析 detail 自由文本。
  • result 字段只表达「成功 / 失败」，不承载错误码； code / reason 字段必须是本章中定义过的标识符。
  • 未列在本章的错误码一律视为 UNKNOWN_ERROR。

建议错误码（完整清单）

SESSION · 会话级错误

错误码符号名 含义 触发场景
SESSION_NOT_FOUND 会话不存在或已终止 对不存在的 / 已终止的会话发起操作
DELIVERY_DECLINED 接收方拒绝该次主动投递（策略、配额或用户决定） 经 delivery_response.code 表达；Server 必须以 session_abort 终止会话（见 09 章）
STORAGE_FULL 接收方存储空间不足，无法容纳投递的文件 经 delivery_response.code 表达
FILE_NOT_FOUND 请求的文件在 Server 上不存在或不可拉取 Server 必须以 session_abort 拒绝（见 09 章）
SESSION_ABORTED 会话被服务端终止 Server 主动终止会话
INVALID_STATE 当前状态不允许该操作 在当前会话状态下执行了该操作不允许的动作
TOO_MANY_SESSIONS 单条控制连接上的并发会话数已达上限 max_sessions_per_connection = 64（见 09 章）；Server 必须以 session_abort（reason = TOO_MANY_SESSIONS）拒绝该请求

TRANSPORT · 传输层错误（UDP/TCP）

错误码符号名 含义 触发场景
UDP_UNAVAILABLE UDP 探测失败 UDP 探测（PROBE）阶段失败
TCP_ERROR TCP 数据面降级通道错误 TCP 数据面降级通道上发生错误
BIND_FAILED 数据面端口绑定失败 数据面端口绑定失败
CONNECTION_FAILED 控制通道连接失败 控制通道建立连接失败
CONNECTION_CLOSED 控制连接已关闭 对端断开或超时
NETWORK_ERROR 网络错误 一般性网络错误

INTEGRITY · 完整性校验错误

错误码符号名 含义 触发场景
CRC32_INVALID 包级校验失败 丢弃该包，不标记位图
SOURCE_FILE_MISMATCH 发送方源文件与请求的 file_hash 不符 摘要对帐的根区间摘要双方一致时判定；必须以 session_abort 终止会话，不得再进入复核轮（见 12 章）
FILE_HASH_MISMATCH 文件级内容哈希不一致 必须按恢复阶梯处理：摘要对帐 → 复核轮 → 仍失配才以 session_abort 终止会话（见 12 章）
INVALID_CHUNK chunk_id 越界或非法 收到越界或非法的 chunk_id
CHUNK_ALREADY_RECEIVED 重复 chunk 幂等丢弃

AUTH · 认证与 ACL 错误

错误码符号名 含义 触发场景
ACL_DENY ACL 拒绝访问 访问控制校验未通过
CLIENT_ID_INVALID client_id 非法 客户端身份非法 / 与认证凭据绑定身份不一致
LOGIN_FAILED 登录认证失败 login 中的认证凭据校验失败
PROTO_VERSION_UNSUPPORTED 协议版本不受支持 见 06 章 login / login_ack
FILE_TOO_LARGE 文件大小超出该会话 chunk_size 可表示的上限 Server 必须以 session_abort 拒绝该请求，且不得创建会话（见 09 章「文件大小上限」）

TIMEOUT · 超时错误

错误码符号名 含义 触发场景
TIMEOUT_NO_ACTIVITY 长时间无活动导致超时 会话级，60 秒
TIMEOUT_PROBE UDP 探测超时 UDP 探测未在期限内完成
TIMEOUT_HEARTBEAT 控制连接心跳超时 30 秒无任何消息（见 06 章）

STORAGE · 持久化与文件系统错误

错误码符号名 含义 触发场景
DATABASE_ERROR SQLite 持久化失败 SQLite 持久化操作失败
FILESYSTEM_ERROR 文件系统操作失败 文件系统读写等操作失败

PROTOCOL · 协议格式与状态错误

错误码符号名 含义 触发场景
MAGIC_MISMATCH 帧头魔数不匹配，判定失步 控制面与 TCP 数据面帧的 magic 均为 0x574E414C（见 06、07 章）
HEADER_CRC_INVALID 帧头 CRC32 校验失败，判定失步 CRC-32/ISO-HDLC；覆盖帧头除自身外的全部字节（见 06、07 章）
FRAME_LEN_INVALID 帧长越界，判定失步 frame_len < 帧头长度或 > max_frame_len；读取指针无法可信推进
INVALID_PACKET 数据包格式非法 长度不足、越界等
SESSION_ID_MISMATCH session_id 不匹配 收到的包 session_id 与本会话不一致
SERIALIZATION_ERROR 控制帧解码失败 定长区长度不足、变长区越界、取值违反约束等
CONTROL_ERROR 控制面错误 控制面处理出错
UNKNOWN_ERROR 未分类错误 未列在本章的错误码一律视为 UNKNOWN_ERROR

终止类与过程类（规范性）

错误码按是否可作为会话终止原因分为两类：

类别含义可否作为 session_abort.reason / 完成消息 code
终止类表示会话本身无法继续（会话被终止）可以
过程类表示传输过程中的局部异常；会话未必终止不可以 —— 必须只记录到日志 / 指标
类别错误码
终止类 SESSION_NOT_FOUND、SESSION_ABORTED、FILE_NOT_FOUND、DELIVERY_DECLINED、INVALID_STATE、TOO_MANY_SESSIONS、FILE_HASH_MISMATCH、SOURCE_FILE_MISMATCH、ACL_DENY、CLIENT_ID_INVALID、LOGIN_FAILED、PROTO_VERSION_UNSUPPORTED、FILE_TOO_LARGE、TIMEOUT_NO_ACTIVITY、DATABASE_ERROR、STORAGE_FULL、FILESYSTEM_ERROR
过程类 UDP_UNAVAILABLE、TIMEOUT_PROBE、TCP_ERROR、BIND_FAILED、CONNECTION_FAILED、CONNECTION_CLOSED、NETWORK_ERROR、TIMEOUT_HEARTBEAT、CRC32_INVALID、INVALID_CHUNK、CHUNK_ALREADY_RECEIVED、INVALID_PACKET、SESSION_ID_MISMATCH、SERIALIZATION_ERROR、MAGIC_MISMATCH、HEADER_CRC_INVALID、FRAME_LEN_INVALID、CONTROL_ERROR、UNKNOWN_ERROR
约束：过程类错误码不得作为 session_abort.reason 或完成消息 code 上线路； 会话因过程类错误而结束时，必须以终止类错误码说明终止原因 （如传输层反复失败导致会话超时 → TIMEOUT_NO_ACTIVITY）。
为何要区分：过程类错误描述的是传输链路的状态， 而 session_abort.reason 描述的是会话为何终止。 把 NETWORK_ERROR 当作终止原因上线路，会让对端误以为「文件有问题」， 实际只是「链路抖了一下，会话超时被清理了」。
失步类错误（MAGIC_MISMATCH / HEADER_CRC_INVALID / FRAME_LEN_INVALID） 属过程类：它们导致连接关闭，会话进入 13 章「中断处理」，不是会话的终止原因。

行为

  • 错误记录日志。
  • INTEGRITY 错误包直接丢弃，且不得写入位图。
  • SESSION 错误触发 session_abort（reason 填对应错误码）。
  • CHUNK_ALREADY_RECEIVED 属幂等情形，静默丢弃即可。
  • 同一错误不得导致状态机进入非法状态。
常见实现陷阱：把自由文本写进 code / reason（不得，必须是本章定义过的标识符）； 用 result 承载错误码；依赖 detail 做分支判断； INTEGRITY 错误包仍写入位图（不得）。
