16 移动端后台限制

本章要点：移动端的后台限制由操作系统决定，协议侧以 「后台视为中断」+ resume_session 恢复的方式适配； 协议不提供「长期后台无 UI 传输」这一能力（见 04 章非目标）。

平台差异

Android

  • 使用 Foreground Service（前台服务）
  • 展示同步状态（通知栏）

iOS

  • 仅前台可用
  • 进入后台视为中断
  • 回到前台需发 resume_session

与恢复机制的衔接

移动端 Client
Server
前台传输中
TRANSFERRING
进入后台 → 视为中断（会话暂停 / 位图保留）
保留位图与临时文件（见 13 章、17 章）
回到前台 → resume_session
resume_ack {next_chunk_id, missing_count, udp_port}
各视角各自回到断线前状态（PAUSED 保持 PAUSED）
实现提示：iOS 的「后台视为中断」与 13 章「暂停后恢复（连接存活）」语义一致； 若连接已断开，则走 13 章「断线重连（连接重建）」路径，由 login 的恢复列表与 login_ack 的权威快照重建状态。
