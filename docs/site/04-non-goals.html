04 非目标（Non-Goals）

本章要点：本章明确本协议不做的事情。 实现超出本章范围的能力前，应先确认它不会与规范中的规范性约束冲突。

非目标清单

非目标说明
公网穿透与互联网规模传输 协议面向可信局域网；不提供 NAT 打洞、relay 或公网可达性方案
数据面的复杂拥塞控制与逐包 ACK 拥塞调节仅以发送端本地策略（AIMD）作用于发送节奏，不进入协议层
多租户不可信网络 安全模型面向局域网内的可信设备（见 20、21 章）
移动端长期后台无 UI 传输 移动端后台限制见 16 章
端到端加密作为协议内建能力 由实现层提供，且不得改变 chunk 与偏移的映射

设计目标 ↔ 非目标 对照

设计目标（03 章）

  • 高效大文件同步
  • 可恢复
  • 乱序写盘
  • 重传裁决清晰
  • 内存与文件大小解耦
  • 分层清晰
  • 发送端策略简化与稳定

非目标（本章）

  • 公网穿透与互联网规模传输
  • 数据面的复杂拥塞控制与逐包 ACK
  • 多租户不可信网络
  • 移动端长期后台无 UI 传输
  • 端到端加密作为协议内建能力
为什么 AIMD 不进入协议层：拥塞调节只作用于发送节奏， 不改变协议语义 —— 两端实现可以采用完全不同的策略，协议行为必须保持一致（见 11 章）。
