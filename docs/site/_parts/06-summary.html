本章要点：控制面是会话状态推进与可靠性裁决的唯一通道，跑在 TCP 上， 一条连接可承载多个并发会话。控制帧 = {{VAR:c06_hdr_size}} 字节定长帧头 + 二进制消息体； 帧头 magic 恒为 {{VAR:c06_magic_value}}（线上字节 {{VAR:c06_magic_bytes}}，小端序）， header_crc32 覆盖帧头中除自身外的 {{VAR:c06_crc_bytes}} 字节。 接收方必须先过 magic → header_crc32 → frame_len 三项校验再读帧体， 任一失败即失步：必须丢弃该连接上未解析的数据并关闭连接， 不得就地「跳过一帧继续解析」。frame_len 上界为 {{VAR:c06_max_frame}}； 定长区一旦发布即冻结，新增字段只能追加在扩展区，接收方必须忽略扩展区。
