magic 恒为 {{VAR:c06_magic_value}}（“LANW”），不随版本变更；线上四字节为 {{VAR:c06_magic_bytes}}。抓包比对必须按线上字节序， 不得按 u32 的字节序反推。 header_crc32 覆盖帧内两段连续区间 （magic ‖ frame_len，以及 msg_type ‖ flags ‖ body_version ‖ reserved），合计 {{VAR:c06_crc_bytes}} 字节， 不是单一连续区间。图中字段偏移与大小均由源文帧格式表抽取（{{VAR:c06_f_magic_off}} 等），不手敲。 frame_len 的字节 0 为最低有效字节（LSB first）：字节序 0 → 1 → 2 → 3 依次存放 u32 的 bit0–7 → bit8–15 → bit16–23 → bit24–31。
