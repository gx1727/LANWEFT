相关错误码的适用情形

错误码适用情形上线路位置
FILE_NOT_FOUND 请求的文件在 Server 上不存在或不可拉取 —— 包括共享清单（catalog）中的条目 已被 Server 移除、而 Client 本地视图滞后的情形。 Server 必须以 session_abort（reason = FILE_NOT_FOUND）拒绝该拉取请求。 session_abort · reason
FILE_TOO_LARGE 声明的文件大小超出 chunk_count / symbol_count 的 u32 上限， 或 chunk_size 不是 1200 的整数倍 / S 超出 [1, 64] （见 09 章「文件大小上限与块参数校验」）。 Server 必须以 session_abort（reason = FILE_TOO_LARGE）拒绝该请求， 且不得创建会话。 session_abort · reason
两者的区分：FILE_NOT_FOUND 说的是「内容不存在」， FILE_TOO_LARGE 说的是「内容存在但声明的大小不可承载」—— 前者由 download_start 的 file_hash 校验失败触发，后者由 size 的上界校验触发； 两者均以 session_abort 的 reason 字段上线路（取值见 19 章）。
