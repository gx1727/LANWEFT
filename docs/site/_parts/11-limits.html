两级在途上限

两级额度必须同时满足（示意）
会话 A 在途量
≤ window（规范默认值 {{VAR:c11_window_default}}）
会话 B 在途量
≤ window（规范默认值 {{VAR:c11_window_default}}）
同一控制连接上全部会话的在途量之和
≤ connection_window（规范默认值 {{VAR:c11_connwin_default}}）
会话之间的额度分配由发送方自行决定，不构成互操作要求；
并发会话不得重复预留同一额度
会话级上限约束单个会话，连接级上限约束整条控制连接上所有会话的在途量之和； 图中“会话 A / B”仅为示意，额度分配策略不属于互操作要求。
