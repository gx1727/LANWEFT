本章要点：数据面数据包为小端序定长头 + 载荷 + 尾部 trailer； 头部 16 字节，尾部长度由会话安全等级决定：lv1 4 字节 CRC32， lv2/lv3 16 字节 keyed MAC / AEAD tag（默认 lv1）。 lv1 的 CRC 变体固定为 CRC-32/ISO-HDLC（zlib crc32）， 两端各选一种会导致所有包校验失败，故本规范不留实现选择空间。 一个数据报承载 K 个 symbol（symbol_size = 1200）， 载荷长度由报文总长反推（头 16 + 载荷 + trailer）；头里带 chunk_symbol 而非长度。 校验失败的包不得标记任何 symbol —— 代价是K 个 symbol，与文件大小无关。
