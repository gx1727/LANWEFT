login_ack 快照记录的字段构成

快照记录 = 定长区（字段顺序与类型取自源文「通用规则」）+ 内联 code 字符串
session_id (u64)
result / direction / state (enum8 × 3)
chunk_count (u32)
chunk_size (u32)
window (u32)
connection_window (u32)
next_chunk_id (u32)
missing_count (u32)
udp_port / tcp_port / code_len (u16 × 3)
定长区共 {{VAR:snapshot_rec_bytes}} 字节 → 紧随其后是 code_len 字节内联的 code 字符串
字段名称、顺序与类型取自源文「断线重连（连接重建）· 通用规则（规范性）」； 定长区长度 {{VAR:snapshot_rec_bytes}} 字节由源文声明。 图中不含手敲偏移：定长区内的字节排布由源文定义，字段类型即其宽度。
条目数上界与可编码性：resume_count 与 sessions_count 必须 ≤ max_sessions_per_connection（{{VAR:sess_cap}}）。 login.resume[] 每条为 {{VAR:resume_rec_bytes}} 字节定长记录 （字段：session_id / next_chunk_id / missing_count / flags）， 恢复列表最大 {{VAR:sess_cap}} × {{VAR:resume_rec_bytes}} = {{VAR:resume_list_max}} 字节； 快照最大 {{VAR:sess_cap}} × ({{VAR:snapshot_rec_bytes}} + code_len) 字节， 均远小于 max_frame_len（{{VAR:max_frame_len_13}}）—— 该上界保证两者始终可编码。
