下载流程时序

下载流程时序：Server → Client，6 个阶段
1 会话建立download_start → download_accept
2 UDP 探测UDP_PROBE → UDP_PROBE_ACK → udp_ready
3 数据传输Server → Client
4 缺失重传Client ⇄ Server
5 进度上报Client → Server
6 完成与终止Client → Server
1 会话建立：Client 发送 download_start → Server 返回 download_accept（含 session_id（u64）/ chunk_count（u32）/ window（u32）/ connection_window（u32）/ udp_port（u16）/ tcp_port（u16））
2 UDP 探测：Client 必须先打开数据面 socket，再从该 socket 发出 UDP_PROBE → Server 返回 UDP_PROBE_ACK → Server 发送 udp_ready；Server 以 PROBE 报文的源地址:端口作为该会话的对端数据面地址
3 数据传输：Server 按 window 连续发送 UDP chunk（批量发送，节奏见 11 章）， 并必须同时遵守连接级的 connection_window
4 缺失重传：Client 每 {{VAR:report_interval}} 发送 missing_chunks （mode=report）→ Server 按 11 章补发缺失块； 收到 Server 的 missing_chunks（mode=request）时， Client 必须在 {{VAR:reply_deadline}} 内应答
5 进度上报：Client 每 {{VAR:progress_interval}} 发布 progress_update （received = 已接收 symbol 数、total = symbol_count，均为 u64）， Server 据此估算链路丢包率并驱动 AIMD（见 11 章）
6 完成与终止：Client 检测位图全真 → 校验 hash → 原子重命名 → 发送 download_complete（接收方发布完成消息，见 06 章）； Server 持久化完成回执后回复 complete_ack
