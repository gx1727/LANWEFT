trailer：lv2/lv3 = 16B keyed MAC / AEAD tag；lv1 = 无
lv1 frame_len = 28 + L；lv2/lv3 frame_len = 28 + L + 16（L 由 frame_len 反推，帧长含帧头与 trailer）
magic frame_len header_crc32 session_id chunk_id flags payload
帧头长度 = 4 + 4 + 4 + 8 + 4 + 2 + 2 = 28 字节； magic 恒为 0x574E414C（“LANW”），线上字节为 4C 41 4E 57（小端序）。
