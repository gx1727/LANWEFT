# 05 协议栈（Protocol Stack）

## 分层结构

应用层 → 控制层（TCP：状态机/重传裁决/会话管理） → 数据层（UDP/TCP：chunk 传输与兜底） → 网络层（LAN）。

## 职责划分

- 控制面拥有最终裁决权
- 数据面仅负责搬运与落盘；**完整性分两层**：包级 CRC32、文件级 Blake3（见 12 章）
- **控制面与数据面相互独立**：一条控制连接承载 N 个会话时，
  数据面端口**可以**被多个会话共用 —— UDP 包头中的 `session_id` 足以区分（见 08 章）
- **完成消息由接收方发布；缺失裁决由接收方发起**（见 10 章「视角定义」）

## 通道与成熟度

| 通道 | 方向 | 状态 |
|------|------|------|
| TCP 控制面 | 双向 | **v0.3.0 已定义**（二进制定长帧格式、握手、权威快照、心跳） |
| UDP 数据面 | 双向 | **已定义**（含 CRC32 变体与校验规则，见 08 章） |
| TCP 数据面 | 兜底 | **已定义**（帧格式、绑定帧与权限校验，见 07 章「TCP 数据面线路格式」） |
